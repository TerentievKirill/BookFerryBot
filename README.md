# BookFerry Bot

**Русский** | [English](README_EN.md)

Telegram-клиент для [BookFerry Server](https://github.com/TerentievKirill/BookFerry).

Бот позволяет искать EPUB-книги через BookFerry, скачивать их прямо в Telegram и одновременно отправлять на настроенные email-адреса.

> **Статус проекта: прототип.** Основной пользовательский сценарий уже работает, но структура интерфейса, названия кнопок и тексты сообщений ещё могут меняться.

## Что умеет бот

- мастер первоначальной настройки;
- выбор встроенного книжного каталога;
- подключение собственного OPDS;
- настройка до пяти email-адресов;
- настройка темы письма;
- поиск по названию книги или автору;
- постраничный просмотр результатов;
- скачивание выбранного EPUB в Telegram;
- отправка того же EPUB на настроенные email;
- просмотр профиля и быстрая смена каталога.

Поиск и скачивание выполняет BookFerry Server. Бот отвечает за Telegram-интерфейс и использует HTTP API backend'а.

```text
Telegram user
      ↓
BookFerryBot
      ↓
BookFerry API
      ↓
book catalog / EPUB source
      ↓
Telegram + configured email
```

## Почему тексты пока находятся в коде

Сейчас проект намеренно находится на стадии прототипа. Пользовательский flow ещё уточняется: меняются формулировки сообщений, состав кнопок и последовательность действий.

Поэтому подписи кнопок и пользовательские тексты пока находятся рядом с handlers и keyboards, где их проще быстро менять вместе с логикой сценария. Для стабильного приложения это было бы неправильной организацией кода, но на текущем этапе отдельный слой ресурсов пришлось бы постоянно синхронизировать с ещё меняющимся интерфейсом.

Когда структура бота устаканится:

1. пользовательские тексты и подписи кнопок будут вынесены в отдельные resource-файлы;
2. handlers останутся только с логикой сценариев;
3. будет добавлен выбор языка и локализация интерфейса.

То есть нынешнее размещение текстов в коде — осознанное временное решение для прототипа, а не финальная архитектура.

## Основные команды

| Команда | Назначение |
|---|---|
| `/start` | начало работы |
| `/settings` | мастер настройки |
| `/catalog` | смена книжного каталога |
| `/profile` | текущие настройки пользователя |
| `/help` | помощь |
| `/about` | информация о проекте |

После настройки отдельная команда для поиска не нужна: достаточно отправить боту название книги или имя автора.

```text

│   │   ├── profile.py

│   │   └── about.py
│   └── keyboards/
```

Проект построен на `aiogram 3`; для обращения к BookFerry API используется `httpx`.

## Локальный запуск

Создайте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

Создайте `.env`:

```env
BOT_TOKEN=telegram-bot-token
API_BASE_URL=https://example.com
```

Запустите бота:

```powershell
python main.py
```

## Docker

```bash
docker compose up -d --build
```
